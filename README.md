# Project Overview

(Note: This is the programming repo. For a the full mechanical design and the final reports, please check out the other repos under this organization)

**Goal**: Develop a working prototype of a boat autonomously navigating exactly to a person offshore and bringing them back to shore.
- Powered by T200 Thruster with force-power tests in a water tank
- Entire control system programmed in Embedded C to Atmega328p
- Navigation system with IMU, GPS, RF modules, and automatic calibration
- Amplifiers, filters, peak-detectors circuits for Sonar (obstacle avoidance)
- Structure designed in Siemens NX and components 3D printed/laser cut
- Successful navigation system after deployment in water

Please see the <a href="https://github.com/Maritime-Mavericks/Programming/blob/main/LiSa_boat_0_2.pdf">report</a> in this repository for a detailed study on this project.

The <a href="https://github.com/HritikRC/Magnetometer-Simulation">Magnetometer Simulation</a> project was used as a visualisation tool for this project and to understand and incorporate the IMU properly into the navigation system.
